# 🚀 Text Analyzer - Analisador de Texto Inteligente em Rust

**Um analisador de texto completo escrito em Rust puro** que realiza análise linguística avançada, detecção de IA, análise de sentimentos e muito mais!

![Rust](https://img.shields.io/badge/Rust-1.70%2B-orange?logo=rust)
![License](https://img.shields.io/badge/License-MIT-blue)
![No Dependencies](https://img.shields.io/badge/Dependencies-0-green)

## 🌟 Características Principais

### 📊 **Análise Completa de Texto**
- **Contagem de palavras e caracteres**
- **Densidade de palavras-chave** - Identifica os termos mais relevantes
- **Detecção de erros ortográficos** comuns em português
- **Análise de legibilidade** - Score de qualidade do texto
- **Resumo automático** em 100 caracteres

### 🤖 **Inteligência Artificial**
- **Detecção de conteúdo gerado por IA** baseado em padrões linguísticos
- **Análise de probabilidade** com indicadores específicos
- **Identificação de padrões** formais e estruturais típicos de IA

### 😊 **Análise de Sentimentos**
- **Classificação positivo/negativo** baseada em léxico emocional
- **Score percentual** de tom emocional
- **Suporte para português** com vocabulário nativo

## 🛠️ Tecnologias

- **100% Rust puro** - Sem dependências externas
- **Algoritmos próprios** - Desenvolvidos especificamente para português
- **Processamento eficiente** - Otimizado para performance
- **Interface CLI intuitiva** - Fácil de usar

## 📦 Instalação

### Pré-requisitos
- Rust 1.70 ou superior ([instalação](https://rustup.rs/))
